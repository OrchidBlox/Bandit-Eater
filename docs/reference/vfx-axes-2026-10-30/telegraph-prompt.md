# VFX Axis: Telegraph

Create a landscape 16:9 educational reference sheet titled **TELEGRAPH (WINDUP WARNING)** on dark charcoal. Use a clean 2x3 grid of equal top-down arena cells with the same scale and lighting. Each cell shows two blocky yellow R15 mannequins in navy clothes: a caster at the warning edge and a rival inside it. Label the cells exactly **1 LANE BAND**, **2 CIRCLE RING**, **3 FAN WEDGE**, **4 TARGET RETICLE**, **5 GROUND SIGIL**, and **6 PATH LINE**, each with a short plain caption. Show chunky-cartoon glowing pre-impact warnings: lane edges and chevrons; dashed circle, spokes, and dark fill; radiating cone; closing crosshair ring; rune circle and hexagram under the caster; and a thin dash path from caster to endpoint. Keep all text legible. No weapons, impact effects, logos, or watermark.
