# Timing and Weight prompt

Create a clean 16:9 educational reference sheet titled **TIMING AND WEIGHT** on a dark charcoal background. Use a 3-by-2 grid of six equal cells. Each cell is a five-frame strip—windup, release, hold, settle, aftermath—showing the same fireball cast by the same blocky yellow R15 mannequin in navy clothes, with a timing bar below. Keep camera, scale, lighting, character, and fireball design identical; change only tempo and weight.

1. **SNAPPY:** Short windup, instant release, tiny hold, fast settle.
2. **HEAVY:** Long gather, slow big release, long aftermath.
3. **FLOATY:** Gentle ease in and out, drifting particles.
4. **RAPID MULTI-HIT:** A rhythm of repeated small pulses.
5. **SLOW BURN:** A long visible build paying off in one hit.
6. **EXPLOSIVE INSTANT:** Almost no windup, then a huge instant release.

Use chunky-cartoon orange-red fire with yellow-hot cores and white puff accents. Make every label and caption legible and exact. No swords, logos, watermarks, extra characters, duplicated cells, cropped figures, or invented text.
