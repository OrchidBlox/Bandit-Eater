# Model briefs

One short brief per model, named `<Model>.md`, so a Codex run reads only what it needs (blender/README.md, section 3). Each brief holds:

- The shared style rules, condensed to what this model needs.
- The model: what it is, the design sheet in `blender/design/`, size in studs, triangle budget, colours, glowing parts, and a "do not" list.
- Bones, and the actions with frame counts and what each looks like.
- The checks: which views and frames go into the composite check images.
