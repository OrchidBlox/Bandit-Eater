# Power moves: 36 casts

Canonical original MrXen0 R15, headless Blender5.2 only; original and live Blender unchanged. References: docs/reference/move-concepts-v1-2026-10-26/{wind,earth,water,fire,sword,shadow,fusion-nature,fusion-arcane,master-sword}.png. Current Config/PowerMoves.luau takes priority over older concept move names/roles.

All 12 kits have three authored clips: Wind, Earth, Water, Fire, Sword, Shadow, Sword_Wind, Sword_Earth, Sword_Water, Sword_Fire, Sword_Shadow, Sword_Sword. Naming BE_PowerMoves_<Power>_<1-3>. Each has a Moving variant, 72 RBXMX files total. These intentionally reuse ten authored archetypes with per-kit head variation and exact move-specific timing: push, throw, wave, raise, slash, rising, slam, stomp, ritual, spin. This is not 36 unique choreography sets. Weapon geometry and VFX are runtime attachments, not embedded in these animations.

Nonlooping Action priority. Ready -> anticipation -> three-frame fast release -> two-frame hold -> thirteen-frame return to ready. Release marker equals current move.Delay exactly, including fractional 30fps frames (.18/.22/.25). Duration is Delay+.5 seconds. Head/chest/arms drive clear silhouettes; Quake has a lifted-foot anticipation. Root translation is identically zero in every export; no mesh deformation or bone scaling. Leg and root weights are zero in Moving variants; fullbody variants retain planted legs where appropriate.

Entry from idle/movement: suggested fade .05s. Moving/airborne actors use Moving variant to preserve locomotion; stationary actors can use fullbody. Exit fade .10s, with recovery ending in ready. Permit higher priority dash/attack, KO, respawn and cancellation to interrupt; no gameplay movement freeze. Release effects remain server-timed, not driven by local animation callbacks. Q projectiles may outlive cast recovery. Runtime playback and transition verification belongs to integration; not claimed by these previews.

Build: Blender -b --factory-startup --python blender/anims/build_power_moves.py -- --export --render. Compose using python blender/anims/build_power_moves.py --compose. Three review sheets cover all36 actions from side and three-quarter views at anticipation, exact Release, hold and ready. Numeric validation checks original rig hash, evaluated-to-R15 mapping, joint lengths, feet, orthonormal export matrices, exact marker times and zero root translation. Configuration has honest empty asset IDs until upload.
